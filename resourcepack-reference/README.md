# Resourcepack-Referenz

Diese beiden PNGs sind die Herzgrafiken aus dem vom Nutzer bereitgestellten Resourcepack.

Das eigentliche Plugin nutzt die dazugehörigen Font-Glyphen aus `assets/minecraft/font/default.json`:

- `U+E01B` → `active_heart.png`
- `U+E01C` → `inactive_heart.png`

Das komplette Resourcepack ist absichtlich nicht in diesem Plugin-Projekt enthalten. Auf dem Server müssen die Spieler das ursprüngliche Resourcepack verwenden.
